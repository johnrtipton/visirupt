01 / The first working port

Cyberpunk 2077.
On the headset.

The Mac version runs directly on Vision Pro. Hands-on testing has confirmed gameplay, aiming, firing and movement in a plain, resizable window.

1280×720Verified native output

✓ Keyboard and mouse gameplay

✓ Trackpad scrolling and window resizing

✓ WASD movement and arrow-key camera turning

Reported responsive in hands-on testing. FPS benchmarks and extended stability testing are still pending.

Playable prototype. Not a VR release.

The current build is a flat game window running natively on visionOS. Stereo rendering, head tracking and VR controller integration remain research and development work.

03 / Developer testing

Early days.
Real progress.

We’re preparing a small developer alpha. The source repository is private while the installation pipeline is packaged and verified.

Follow the developer on GitHub ↗

What testing will require

  • For this prototype: your own compatible Mac copy of Cyberpunk 2077
  • An Apple Silicon Mac with Xcode
  • A Vision Pro set up for local development
  • Enough free storage for the game assets

No public installer is available yet. Other Mac apps and games are future porting candidates; compatibility beyond this tested build and M2 headset has not been established.
